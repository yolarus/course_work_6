# Трекер полезных привычек

## Описание
API-сервис для создания полезных привычек и напоминания о них. В приложение встроен следующий функционал:
1. Регистрация и авторизация пользователей через JWT-токен. 
2. Настроены различные права доступа для авторизованных, неавторизованных пользователей и администраторов:
   * Доступ к редактированию объектов открыт только для их владельцев и суперпользователя.  
   * На страницах со списками объектов (кроме списка публичных привычек) отображаются только объекты владельцев, и суперпользователи видят все объекты.
   * Неавторизованным пользователям доступ закрыт ко всем маршрутам.
3. После создания привычки, автоматически приходит напоминание о ее выполнении в ТГ-боте
4. Созданы кастомные команды 'python manage.py load_habits' и 'python manage.py load_users' для заполнения БД

## Установка проекта
1. Клонирование проекта из [GitHub](https://github.com/yolarus/healthy-habits-tracker) по HTTPS-токену или SSH-ключу.
2. Создание и заполнение файла .env своими данными.
3. Установить на компьютер брокер Redis

## Установка зависимостей
1. Перейти в настройки Pycharm -> Setting -> Project -> Python Interpreter.
2. Добавить локальный интерпретатор с менеджером пакетов Poetry.
3. Выполнить команду в терминале PyCharm 'poetry install --no-root'.

## Запуск
1. Прописать в командной строке 'python manage.py load_users'.
2. Прописать в командной строке 'python manage.py load_habits'. 
3. Прописать в командной строке 'python manage.py runserver'.
4. Прописать в командной строке 'python manage.py redis-server'.
5. Прописать в командной строке 'celery -A config worker --beat --scheduler django --loglevel=info'.
